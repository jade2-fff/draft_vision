========================================================
相机内参标定说明（fx/fy/cx/cy + 畸变）
========================================================

目的：算出相机镜头的真实内参，让深度(depth)算得准。
输出：config/dart_intrinsics.yml

内参不准 → 深度和 x 尺度都错 → yaw 和距离全偏。
这是让 depth 数值准确的关键一步。


========================================================
三条铁律（做错就白标）
========================================================

1. 【焦距/对焦全程不动】
   标定内参、标定外参、比赛运行，三者焦距必须完全一致。
   - 变焦镜头：焦距锁死，绝不能变焦。
   - 对焦环：调到比赛用的清晰状态后锁死/贴胶带固定，不再动。
   标定中途调焦 = 内参作废。

2. 【不用填满画面】
   单张棋盘格只占画面一小块完全可以。
   要的是"多张图加起来，角点覆盖画面每个区域"，不是单张填满。

3. 【角点要够大够清】
   棋盘格在画面里角点间距 > 10 像素才够用。
   太小(< 5像素)标不准。板不够大就把板拉近，或换大板。


========================================================
关键认知：覆盖画面，不是填满画面
========================================================

畸变在画面边缘最明显，必须靠边缘的角点才能标出畸变系数。
所以要让棋盘格在很多张图里，分别出现在：

   左上   上中   右上
   左中   中心   右中
   左下   下中   右下
   还要有各种倾斜角度

20 张摞起来，角点铺满整个画面（尤其四角/边缘）→ 内参才准。
任何单张都不需要填满。


========================================================
拍不清 / 拍不够大 怎么办
========================================================

问题：对焦锁在远处(如25m)，近处拍标定板模糊，角点检测不到。
      或标定板离得远，在画面里太小，角点太密标不准。

解法（按优先级）：

方案A：调小光圈增大景深（最优，如果相机能调光圈）
   光圈调小(f值调大) → 景深变大 → 标定板拉到 3~5m 也清晰。
   板子近了在画面里更大，角点更密，标定质量最高。
   代价：进光少、画面暗 → 运行时按 + 加曝光、] 加增益补偿。
   调完光圈锁死，标定+比赛全程不动。

方案B：用大标定板在清晰范围(10~20m)拍
   板子够大(格子100mm或更大)，10~20m 处角点仍够大。
   在这个距离多角度、多位置拍，覆盖画面各区域。

方案C：屏幕显示棋盘格
   平板/显示器显示棋盘格图案，放到清晰距离拍。
   屏幕自发光、平整、清晰。需量好屏幕上一格的实际 mm。


========================================================
标定板参数
========================================================

corners_x = 横向内角点数（内部交叉点数，不是格子数）
corners_y = 纵向内角点数
square_mm = 每格真实边长(mm)

例：10列×7行格子 → 内角点 9×6
本项目示例命令用 10 7 50，按你实际板子改。


========================================================
操作步骤
========================================================

1. 先固定焦距/对焦/光圈
   - 相机架好，对焦调到比赛清晰状态
   - 光圈若要调大景深，现在调好
   - 全部锁死，之后不再动任何镜头调节

2. 停服务
   systemctl --user stop dart
   pkill -9 dart
   sleep 2

3. 清空旧图
   cd ~/Desktop/dart_standalone_new
   rm -f captures/*.jpg

4. 拍内参图
   ./build_zcode/dart

   运行中按键：
     +/=  曝光+2ms（调亮看清棋盘格）
     -    曝光-2ms
     ]    增益+2
     [    增益-2
     c    存图
     q    退出

   拍摄要求：
   - 标定板在"当前焦距清晰"的距离（能看清角点）
   - 让棋盘格分别出现在画面 9 个区域（中心+四角+四边）
   - 加各种倾斜：正对、左倾、右倾、上仰、下俯
   - 再加不同远近
   - 每个姿势按一次 c
   - 一共 15~20 张
   - 每张棋盘格清晰、完整、角点间距 > 10 像素、不反光、不过曝

   拍完按 q 退出。

5. 生成内参（假设 10×7 内角点、50mm 格）
   ./build_zcode/calibrate_intrinsics 10 7 50 config/dart_intrinsics.yml captures/capture_*.jpg

   命令格式：
   ./build_zcode/calibrate_intrinsics <corners_x> <corners_y> <square_mm> <输出yml> <图片...>

6. 看输出的 RMS 重投影误差
   < 0.5  很好
   < 1.0  可用
   > 1.5  重拍（图太少/角点太小/角度不够/不清）

   同时看 fx/fy/cx/cy：
   - cx 应约等于图像宽度的一半
   - cy 应约等于图像高度的一半
   差太多说明标定有问题。

7. 备份
   cp config/dart_intrinsics.yml ~/dart_intrinsics_backup.yml


========================================================
验证
========================================================

标好内参后运行：
   ./build_zcode/dart

启动日志应出现：
   [Solver] camera intrinsics loaded: ... fx=... fy=... cx=... cy=...

没这行说明内参没加载，用的还是默认占位值(800/320/240)，深度不准。

之后接着标外参(见 docs_飞镖视觉标定说明.txt 第二步)。
外参依赖内参，顺序不能反。


========================================================
常见错误
========================================================

1. RMS 太大(>1.5)
   - 图太少 → 拍到 15~20 张
   - 角点太小 → 板拉近或换大板(调光圈增景深)
   - 只在中间拍 → 要覆盖画面四角/边缘
   - 角度单一 → 加倾斜
   - 过曝/模糊 → 调曝光、保证清晰

2. 棋盘格检测失败 / OK 的图太少
   - 图糊、反光、过曝
   - corners_x/corners_y 填错(填成格子数了，应填内角点数)

3. 中途调了焦距/对焦/光圈
   - 内参作废，全部重拍，且这次固定死镜头再标

4. cx/cy 明显不在画面中心附近
   - 标定质量差，重拍
