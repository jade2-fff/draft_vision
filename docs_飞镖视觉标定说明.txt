========================================================
飞镖视觉标定说明（内参 + 外参 完整流程）
========================================================

程序发给下位机的三个值：
  x = 目标相对相机的水平偏移(mm)，右为正
  y = 前向深度(mm)
  z = valid，1=有目标 0=无目标
下位机自己算 yaw = atan2(x, y)，并自行判断到位停止。
（垂直分量已丢弃，所以绿灯在镗准线下方的机械偏移不影响 yaw）


========================================================
重要：标定顺序
========================================================

必须先标内参(B)，再标外参(A)。
外参用 PnP，依赖内参；内参没标好，外参也不准。

  第一步：相机内参标定  → config/dart_intrinsics.yml
  第二步：平面外参标定  → config/dart_plane_pose.yml

内参标定：标定板放在相机近处(1~3m)，多角度多张。
外参标定：标定板放在 25m 目标平面上。
两步用的照片不一样，不要混用。


========================================================
标定板参数（先量清楚）
========================================================

corners_x = 横向内角点数（不是格子数，是内部交叉点数）
corners_y = 纵向内角点数
square_mm = 每个格子真实边长(mm)

例：10列×7行格子的板 → 内角点 9×6
    本项目示例用 10 7 50（按你实际板子填）


========================================================
公共操作：拍标定图（按 c 存图）
========================================================

先停服务，避免抢相机：
  systemctl --user stop dart
  pkill -9 dart
  sleep 2

运行程序：
  cd ~/Desktop/dart_standalone_new
  ./build_zcode/dart

运行中按键：
  +  或  =   曝光 +2ms（调亮，看清标定板）
  -          曝光 -2ms（调暗，看绿光用）
  ]          增益 +2
  [          增益 -2
  c          保存当前帧到 captures/
  q          退出

看不清标定板就按 + 加曝光、] 加增益，直到棋盘格清晰，再按 c。
每按一次 c 存一张：captures/capture_00.jpg, capture_01.jpg ...


========================================================
第一步：相机内参标定（B）
========================================================

目的：算出真实 fx/fy/cx/cy 和畸变，让深度算得准。

1. 停服务
   systemctl --user stop dart
   pkill -9 dart
   sleep 2

2. 清空旧图
   cd ~/Desktop/dart_standalone_new
   rm -f captures/*.jpg

3. 拍内参图（关键：标定板在相机近处 1~3m）
   ./build_zcode/dart

   拍摄要求：
   - 标定板离相机 1~3m
   - 换不同角度：正对、左倾、右倾、上仰、下俯
   - 换不同位置：画面中心、四个角都要拍到
   - 换不同远近
   - 每个姿势按一次 c
   - 一共拍 15~20 张
   - 棋盘格要清晰、完整、不反光、不过曝

   拍完按 q 退出。

4. 生成内参（假设 10×7 内角点、50mm 格）
   ./build_zcode/calibrate_intrinsics 10 7 50 config/dart_intrinsics.yml captures/capture_*.jpg

   命令格式：
   ./build_zcode/calibrate_intrinsics <corners_x> <corners_y> <square_mm> <输出yml> <图片...>

5. 看输出的 RMS 重投影误差
   < 0.5  很好
   < 1.0  可用
   > 1.5  重拍（图太少/不清/角度不够）

   还会打印 fx/fy/cx/cy，确认 cx/cy 大约在图像宽高的一半附近。

6. 备份内参
   cp config/dart_intrinsics.yml ~/dart_intrinsics_backup.yml


========================================================
第二步：平面外参标定（A）
========================================================

目的：算出相机相对 25m 目标平面的位置姿态(外参)。

前提：内参(第一步)已经标好，config/dart_intrinsics.yml 已存在。

1. 停服务
   systemctl --user stop dart
   pkill -9 dart
   sleep 2

2. 清空旧图和旧外参
   cd ~/Desktop/dart_standalone_new
   rm -f captures/*.jpg config/dart_plane_pose.yml

3. 拍外参图（关键：标定板贴在 25m 目标平面上）
   ./build_zcode/dart

   拍摄要求：
   - 相机固定在比赛位置，不要动
   - 标定板贴在目标光源所在的那个平面上，保持水平
   - 可以只拍 1 张（贴靶心），也可多位置拍几张更稳
   - 每个位置按 c
   - 按 q 退出

4. 准备外参配置
   cp config/plane_captures.example.yml config/plane_captures.yml
   nano config/plane_captures.yml

   填写：
   corners_x / corners_y / square_mm  = 标定板参数
   每张 image                          = 实际拍的文件名 captures/capture_00.jpg
   每张 board_center_mm: [X, Y]        = 该张标定板中心在目标平面坐标系的真实位置(mm)
   每张 board_yaw_deg                  = 标定板旋转角，水平填 0

   目标平面坐标系：靶面中心=(0,0)，X向右为正，Y向上为正，单位 mm。
   单张标定时 board_center_mm 填 [0.0, 0.0] 即可。

5. 生成外参
   ./build_zcode/calibrate_plane_pose --multi config/plane_captures.yml config/dart_plane_pose.yml

   成功输出：Wrote config/dart_plane_pose.yml ... total_points=...
   每张图旁生成 .preview.jpg，打开确认棋盘格角点画对了。

6. 备份外参
   cp config/dart_plane_pose.yml ~/dart_plane_pose_backup.yml


========================================================
第三步：运行验证
========================================================

1. 运行
   cd ~/Desktop/dart_standalone_new
   ./build_zcode/dart

2. 启动日志应出现（两个都要有）：
   [Solver] camera intrinsics loaded: ... fx=... fy=... cx=... cy=...
   [Solver] plane pose loaded: ... points=...

   如果内参没加载，会用默认占位值(800/320/240)，深度不准。

3. 日志每帧打印：
   x_mm=...  depth_mm=...  yaw=...  pv=1

4. 验证：
   - 镗准线水平对准目标时，x_mm 应过 0（左负右正）
   - depth_mm 应接近真实距离（25m 目标 约 25000mm）
   - yaw = atan2(x, depth)，对准时接近 0

   depth 明显不对 → 内参没标好，重标第一步。


========================================================
第四步：启动自启动服务
========================================================

验证 OK 后，按 q 退出手动程序，启动服务：
  systemctl --user restart dart
  journalctl --user -u dart -f


========================================================
什么时候要重新标定
========================================================

重标内参(B)：换了相机、换了镜头、改了分辨率。
重标外参(A)：相机位置/角度变了、目标平面位置变了、车/发射点位置变了。

日常开机、重启、开关服务，都不需要重标。
外参依赖内参，若重标内参，外参也要跟着重标。

========================================================
常见错误
========================================================

1. 内参 RMS 太大(>1.5)
   图太少 / 角度不够 / 棋盘格不清 / 过曝 / 内角点数填错
   → 多拍、拍全画面各区域、多角度倾斜、调曝光

2. depth 数值明显不对
   内参没标好或没加载。看启动日志有没有 camera intrinsics loaded。

3. 棋盘格检测失败
   图糊 / 太小 / 反光 / corners_x/corners_y 填错(填成格子数了)

4. pv 一直 0
   没有 dart_plane_pose.yml / 外参没标 / 没识别到目标

5. 相机打不开 EnumDevices failed: 0x80000006
   同时跑了服务和手动程序，两个抢相机。
   先 systemctl --user stop dart 再手动跑。

6. 串口未连接
   设备号变了。程序已自动检测 ttyACM0~3，插好下位机即可。


========================================================
下位机需要做的（转告下位机同学）
========================================================

1. 下位机接收当前是注释状态，必须取消注释、启用接收，
   否则 com.x/com.y/com.z 永远是 0。

2. 字段映射：
   com.x = 水平偏移(mm)，右为正
   com.y = 深度(mm)          ← 深度在这里，不是 com.distance
   com.z = valid，1有目标 0无目标

3. yaw = atan2(com.x, com.y)   用 com.y 当深度，别用 com.distance。

4. 到位判断由下位机做：yaw 接近 0 就停，避免来回晃。

5. 深度量程放大到 2.5万mm，解析仍是 /100。
